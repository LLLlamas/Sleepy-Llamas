# Moonlog PWA Spec Archive

This file is now an archive of the original Moonlog product direction. The
current implementation source of truth is [`../MASTER.md`](../MASTER.md).

## Original Intent

Moonlog is an offline-first PWA for logging newborn feeds, diapers, sleep, and
notes through the night. It is meant to be fast, one-handed, low-glare, private,
and useful during a 3 a.m. handoff.

## Constraints That Still Matter

- One-handed and thumb-reachable.
- Dark and low-glare by default.
- Fast over exhaustive.
- Offline-first with local-only data.
- Glanceable status: last feed, last diaper, and current sleep state.

# Moonlog

Moonlog is the offline-first newborn night-logging PWA in this repo.

Use [`../MASTER.md`](../MASTER.md) as the current source of truth for product
behavior, implementation notes, commands, deployment, and file maps.

Quick commands:

```bash
npm install
npm run dev
npm run typecheck
npm run build
npm run preview
```

Moonlog stores data locally in IndexedDB. It has no backend and does not transmit
care logs.
